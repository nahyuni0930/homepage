# 아이누리 배움터

누리과정과 표준보육과정을 쉽고 따뜻하게 소개하는 정적 홈페이지입니다.

## 구성

- `index.html`: 홈페이지 콘텐츠와 구조
- `styles.css`: 디자인 시스템과 반응형 스타일
- `script.js`: 모바일 메뉴 및 교육 영역 전환 기능

별도의 프레임워크나 빌드 과정 없이 브라우저에서 바로 실행할 수 있습니다.
`index.html`을 열거나 정적 파일 서버를 사용해 확인하세요.

GitHub 저장소를 Vercel에 연결할 때 Framework Preset을 `Other`로 선택하고
Build Command는 비워 두면 배포할 수 있습니다.
